Incident Report: INC-2026-0142

Summary

On June 5, 2026, the Payment Service experienced a complete outage lasting 47 minutes. All order payments failed during this window, impacting approximately 2,300 customers.

Timeline

Time (UTC)Event
14:23CloudWatch alarm triggers: Payment Service error rate > 50%
14:25On-call engineer Alex Johnson paged
14:28Alex confirms outage, begins investigation
14:35Root cause identified: Stripe API key expired
14:42New API key rotated and deployed
14:50Service recovery confirmed, error rate back to normal
15:10All queued payments reprocessed successfully

Root Cause

The Stripe API key used by the Payment Service expired on June 5 at 14:22 UTC. The key rotation process, managed by the Security Team, failed to update the secret in AWS Secrets Manager before expiration.

Impact

  • 2,300 customers experienced payment failures
  • Revenue delay of approximately $340,000
  • 47 minutes of payment processing downtime
  • NPS impact: estimated -2 points
